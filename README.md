# 🎤 猜歌王

猜歌小遊戲，純前端、不需要安裝任何東西。共 480 位歌手（台灣 100、台語 50、中國 50、日本 50、韓國 50、歐美 150、拉丁 10、印度 10、泰國 10），包含一份「全球百大」與台灣、台語、中國、日本、韓國、歐美、拉丁、印度、泰國九個地區，完整名單見 `js/artists.js`。

**選歌手**：點首頁的「目前歌手」卡片打開選歌面板。

- 搜尋：中文、英文、暱稱都可以（例如「女神卡卡」「霉霉」「防彈」「jay z」）
- 分類：最近、全球百大（顯示名次）、依風格（沿用猜歌手的歌單分段）、各地區、全部
- 首頁卡片下方：最近玩過的歌手，點一下直接換；第一次來會列百大前幾名
- 骰子按鈕：不知道選誰時，從全球百大、全部或某個風格抽三位，挑一位順眼的；不喜歡可以再抽
- 鍵盤：首頁按 `/` 打開，`↑` `↓` 選擇，`Enter` 確定，`Esc` 關閉；在搜尋框按 `Enter` 直接選第一筆

網址後面加 `#歌手代號` 可以直接指定歌手，例如 `#yoasobi`、`#mj`、`#jay`（代號見 `js/artists.js` 的 `id`）。

## 玩法

首頁先選歌手，再從五種玩法裡挑一種。猜歌手不看選好的歌手，而是另外選一個歌單：

| 模式 | 說明 | 計分 |
| --- | --- | --- |
| 🎧 聽歌猜歌 | 用 iTunes 官方 30 秒試聽片段，從 1 秒開始聽，可以逐步解鎖 3／7／15 秒 | 100／70／40／20 分 |
| 🔎 線索猜歌 | 依序揭露冷知識 → 專輯與年份 → emoji | 100／60／30 分 |
| 💬 歌詞猜歌 | 看一兩句歌詞猜歌名，提示會再多給一句、再給專輯資訊 | 100／60／30 分 |
| ✏️ 歌詞填空 | 給歌名和一句挖空的歌詞，選出被挖掉的字；提示會給上一句、下一句 | 100／60／30 分 |
| 🗣️ 猜歌手 | 選一個歌單，放一首歌猜是誰唱的；片段從 2 秒開始，可解鎖 5／10／20 秒 | 100／70／40／20 分 |

**猜歌手的歌單**（`js/groups.js`）：四個選項都從同一個歌單挑，所以同歌單的歌手聲線、曲風、年代相近，不能一聽語言就猜出來。
大亂鬥、華語天后、華語男聲、台灣樂團、華語饒舌、台語天后、台語男聲、經典老歌、J-POP、K-POP、歐美天后、歐美男聲、嘻哈饒舌、搖滾樂團、電音派對、拉丁熱浪、印度與泰國。
結算時每題旁邊有「玩這位」，點了就換成那位歌手，回首頁接著玩猜歌名。
這個模式每位歌手只查一次 iTunes，不翻完整專輯，避免碰到 iTunes 每分鐘的查詢上限。

歌詞來自 [LRCLIB](https://lrclib.net)，遊戲進行時才即時抓取，不存在專案裡；每題只顯示一兩句片段。

線索模式的題庫是手寫的（`js/clues/`）。沒有手寫題庫的歌手會改用 iTunes 資料自動出題：發行年份與曲長 → 專輯名稱（遮住歌名）→ 專輯封面。

- 每題四選一，可選 5／10／20 題。
- 難度：**經典**只考熱門歌、**混合**全部都考、**冷門**只考專輯歌與合作曲這些非主打。
- 聽歌模式會抓歌手所有專輯的完整曲目（最多 80 張），不只是 iTunes 搜尋前幾名的熱門歌。
- 手寫題庫：Lady Gaga 87 首、Ariana Grande 72 首、Michael Jackson 59 首、Bruno Mars 46 首、YOASOBI 22 首。
- 鍵盤快捷鍵：`1`～`4` 選答案、空白鍵播放片段。
- 結算後可產生 IG 限時動態尺寸（1080×1920）的成績圖：分數、稱號、答對率、平均聽幾秒（或用幾條線索）、Wordle 式的每題格子。手機可直接分享，電腦可下載。背景預設是這位歌手的第一張專輯封面（這一局出現過的專輯優先），也可以換其他封面或改回唱片，封面四邊會霧化接進模糊的底色，分數和格子的顏色也會改從封面取。
- 各模式、各題數的最佳紀錄存在瀏覽器的 localStorage。

## 執行

直接用瀏覽器打開 `index.html` 就能玩；或啟動一個靜態伺服器：

```bash
npx http-server .
```

## 部署

網站放在 Cloudflare Workers（`guesssong.party`），設定在 `wrangler.jsonc`。repo 已接上 Workers Builds：

- 推到 `main` 會自動部署到正式站。
- 推到其他分支會建一個預覽網址，PR 底下的 `Workers Builds` 檢查可以點進去看。
- `.assetsignore` 列出不上傳的檔案（說明文件、工具腳本、設定檔）。

手動部署：`npx wrangler deploy`。

## 檔案結構

```
index.html      畫面結構
style.css       樣式
js/artists.js   歌手清單：搜尋關鍵字、配色、稱號
js/clues/*.js   各歌手的線索題庫（自己寫的背景知識，不引用歌詞）
js/itunes.js    串接 iTunes Search API、過濾 remix／live／karaoke 等重複版本
js/groups.js    猜歌手模式的歌單分組
js/lyrics.js    串接 LRCLIB 歌詞、清掉作詞作曲名單、出歌詞題目
js/share-card.js 產生限動尺寸的成績圖
js/game.js      遊戲流程與計分
```

## 更新網站

改完 `style.css` 或 `js/` 底下的檔案後，推送前先跑：

```bash
python3 scripts/bump-version.py
```

它會在 `index.html` 引用的 CSS／JS 網址後面加上新的版本號，避免瀏覽器拿到新網頁卻配上快取裡的舊樣式。

## 新增歌手

在 `js/artists.js` 加一筆資料（`region` 地區、`terms` 搜尋關鍵字、`match` 比對 iTunes 歌手名稱的規則）即可，聽歌模式馬上能玩；想要手寫線索的話，再照 `js/clues/gaga.js` 的格式新增檔案，並在 `index.html` 引入。

題庫格式（`defineClues`）：`t` 歌名、`a` 專輯、`y` 年份、`f` 冷知識、`e` emoji、`w` 自訂第二條線索、`deep: 1` 標記為冷門歌。
